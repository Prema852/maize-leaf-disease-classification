# Extended Evaluation — MobileNetV2

This folder contains the results from the extended evaluation of the MobileNetV2 maize leaf disease classification model.

## Experiment Summary

- **Test images:** 2,331
- **Test accuracy:** 99.10%
- **Classes:** Healthy, Common Rust, Northern Leaf Blight, and Cercospora Leaf Spot / Gray Leaf Spot.

## Results

This folder will contain the confusion matrix, classification report, training and validation graphs, and actual-versus-predicted image galleries.

The extended evaluation is a separate experiment from the initial evaluation. Results should be interpreted according to their respective dataset and evaluation setup.
